\title{FINN PR results: analytical FIFO sizing, folding optimizer and DWC padding on the finn-examples models}
\date{Snapshot 2026-10-28 11:55 (campaign variant 2)}
\begin{document}\maketitle
Each table is one PR's feature test on every finn-examples model: the stitched IP is built and simulated, and a test passes when its output equals the golden output and its rtlsim throughput is at least 0.98$\times$ the build's own analytic estimate. The results come from the test campaign's integration branches; how they relate to the PR branches:
\begin{itemize}
\item \textbf{Analytical FIFO sizing (Xilinx/finn\#1185)}: \texttt{feature/analytical-fifo-sizing} at 4ce1bd188 (2026-10-28); results from \texttt{test2/fifo} at e3824a18e (2026-10-27): same sizing rules (incl.\ the StreamingConcat join floor and the throttled-cap pair test); the PR adds the upstream/dev sync (free-running MVAU/VVAU HLS cores) and the tree-model refactor, which gives the same depths on all checked models except 2 of bert's 84 FIFOs.
\item \textbf{Folding optimizer}: \texttt{feature/set-folding-optimizer} at 22171408a (2026-10-28); results from \texttt{test2/folding} at 475358f09 (2026-10-27): SetFolding code identical; the campaign branch also carries the FIFO sizing PR (FIFOs sized with heuristic\_analytical) and the resource-estimate fixes.
\item \textbf{DWC padding (generalized data width converter)}: \texttt{feature/dev/generalized-datawidthconverter} at 6ea413550 (2026-10-22); results from \texttt{test2/dwc} at 42388e033 (2026-10-27): DWC PR fully contained; also carries the FIFO sizing PR and the resource-estimate fixes.
\end{itemize}
Key: \checkmark{} passed; $\times$ failed, with its cause: $^{\mathrm{est}}$ rtlsim below 0.98$\times$ the build's own estimate (an estimate gap or a FIFO/throughput shortfall), $^{\mathrm{out}}$ output differs from the golden output, $^{\mathrm{bld}}$ build failed, $^{\mathrm{tgt}}$ the optimizer's estimate missed the target; skip = skipped, run = running, blk = blocked (its small run failed), n/f = started but did not finish, -- = not run. Known estimate gaps outside these PRs (separate estimates PR): LabelSelect\_hls restarts per frame (+4 cycles, tfc) and the tiled MVAU's group stalls (bert).
