\clearpage\section*{Bugs fixed in the FINN compiler (outside our transformations)}
Found while making the feature tests pass; each fix is a separate branch (dev-side PR), not part of the FIFO-sizing, folding or DWC PRs. Line counts include tests and docs.
\begin{enumerate}
\item \textbf{MVU output queue overflow at SF = 1} (issue 007, 012). mvu\_vvu\_axi's output queue was sized for an outdated core latency (non-power-of-2 SIMD and non-INT8 DSP58 cores are deeper) and a registered output lock let one more item in: under output backpressure results were overwritten and read back as X (espcn: whole pixels zeroed). The RTL's own assertion fired unseen.\\
\emph{Fix:} +97/$-$12 lines, branch \texttt{feature/dev/mvu-output-queue}, commit(s) \texttt{55a0edb83}.\\
{\footnotesize \texttt{finn-rtllib/mvu/mvu\_vvu\_axi.sv} (+15/$-$12); \texttt{tests/fpgadataflow/test\_fpgadataflow\_mvau.py} (+82/$-$0)}
\item \textbf{Tiled MVAU expected cycles} (issue 009). get\_exp\_cycles multiplied by TH (bert estimate 4x pessimistic); upstream's c15fb8a9a drops it, plus the two per-group stalls of the tiled MVU (activation replay, output reorder) modelled from the RTL.\\
\emph{Fix:} +241/$-$30 lines, branch \texttt{feature/dev/mvau-exp-cycles}, commit(s) \texttt{187efdac7 cbd53df4c}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/matrixvectoractivation.py} (+97/$-$6); \texttt{src/finn/custom\_op/fpgadataflow/rtl/finn\_loop.py} (+5/$-$3); \texttt{tests/fpgadataflow/test\_fpgadataflow\_finnloop.py} (+9/$-$21); \texttt{tests/fpgadataflow/test\_fpgadataflow\_mvau.py} (+130/$-$0)}
\item \textbf{StreamingSplit/Concat at 5 cycles per word} (issue 010, 012). the generated HLS top was not pipelined (interval 5) while the estimate said 1 word/cycle; a dataflow pragma makes them 1 word/cycle (and smaller).\\
\emph{Fix:} +61/$-$0 lines, branch \texttt{feature/dev/split-concat-dataflow}, commit(s) \texttt{bcb838bbb}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/hls/concat\_hls.py} (+4/$-$0); \texttt{src/finn/custom\_op/fpgadataflow/hls/split\_hls.py} (+4/$-$0); \texttt{tests/fpgadataflow/test\_fpgadataflow\_concat.py} (+27/$-$0); \texttt{tests/fpgadataflow/test\_fpgadataflow\_split.py} (+26/$-$0)}
\item \textbf{GlobalAccPool on non-square inputs} (issue 011). AccPool\_Batch assumed a square image: the transformer token pool ([1,1,64]) summed one token only.\\
\emph{Fix:} +53/$-$13 lines, branch \texttt{fix/011-up (upstream PR)}, commit(s) \texttt{d87bf52e3}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/hls/globalaccpool\_hls.py} (+45/$-$8); \texttt{tests/fpgadataflow/test\_fpgadataflow\_globalaccpool.py} (+8/$-$5)}
\item \textbf{Requant\_rtl with unsigned inputs} (issue 011). the RTL reads its input as signed but specialization accepted any integer type: UINT8 values >= 128 became negative (radioml, vision).\\
\emph{Fix:} +31/$-$4 lines, branch \texttt{fix/011-up (upstream PR)}, commit(s) \texttt{aff7232c9}.\\
{\footnotesize \texttt{src/finn/transformation/fpgadataflow/specialize\_layers.py} (+4/$-$3); \texttt{tests/fpgadataflow/test\_fpgadataflow\_requant.py} (+27/$-$1)}
\item \textbf{Per-frame HLS overhead in MVAU\_hls / LabelSelect\_hls estimates} (issue 002). the HLS top function is not frame-pipelined: +7 / +4 cycles per frame missing from get\_exp\_cycles (tfc/MLP rtlsim at 0.53x of the estimate).\\
\emph{Fix:} +21/$-$1 lines, branch \texttt{feature/dev/hls-exp-cycles-overhead}, commit(s) \texttt{2169d7b6d}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/hls/labelselect\_hls.py} (+9/$-$0); \texttt{src/finn/custom\_op/fpgadataflow/hls/matrixvectoractivation\_hls.py} (+10/$-$0); \texttt{tests/fpgadataflow/test\_set\_folding.py} (+2/$-$1)}

\emph{Fix:} +2/$-$1 lines, branch \texttt{feature/dev/set-folding-optimizer}, commit(s) \texttt{48a274bdb}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/matrixvectoractivation.py} (+2/$-$1)}

\emph{Fix:} +10/$-$0 lines, branch \texttt{feature/dev/set-folding-optimizer}, commit(s) \texttt{474ea4474}.\\
{\footnotesize \texttt{src/finn/custom\_op/fpgadataflow/streamingdatawidthconverter.py} (+10/$-$0)}
